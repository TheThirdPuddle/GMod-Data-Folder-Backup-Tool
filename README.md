### About This App:
* This app is made to reduce the amount of clicks to back up your Gmod's data folder down to 1 (Powered by PyQt5)


---
### Notice
you may need to run this app as an administrator to perform backups correctly. you don't need to, but it's recommended so you won't encounter problems when backing up

if you are going to:
* right clck on the executable, and press "Run as Administrator"

---
### how to use:
1. Run "GMDFBT" as 'Administrator' (if you have to) (refer to the notice)
2. (optional) Select your GMod's `data` directory
3. (optional) Select your backup directory
4. Press `Create backup` (app may freeze during the process)
5. Close app once done
